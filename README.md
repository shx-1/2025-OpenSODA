## 关于大赛

OpenSODA（Open Source Software Supply Chain Lighting Program）是一项全国性开源软件供应链赛事，旨在：
- 培养开源人才
- 促进开源生态发展
- 提升软件供应链安全意识
- 推动产学研合作

## 使用说明

### 查看演示文稿

#### 方法一：使用Marp工具（推荐）

1. 安装Marp CLI：
```bash
npm install -g @marp-team/marp-cli
```

2. 预览PPT：
```bash
marp presentation.md --preview
```

3. 导出为PDF：
```bash
marp presentation.md --pdf
```

4. 导出为PowerPoint：
```bash
marp presentation.md --pptx
```

5. 导出为HTML：
```bash
marp presentation.md --html
```

#### 方法二：使用VS Code扩展

1. 安装 [Marp for VS Code](https://marketplace.visualstudio.com/items?itemName=marp-team.marp-vscode) 扩展
2. 打开 `presentation.md` 文件
3. 点击右上角的预览按钮即可查看演示效果

#### 方法三：在线查看

直接在GitHub上查看 `presentation.md` 文件，虽然不是演示模式，但内容完整。

## 参赛指南

### 快速开始

1. **注册报名**：访问官方网站完成注册
2. **选择赛道**：根据兴趣选择合适的赛道
3. **准备作品**：开发项目并准备文档
4. **提交作品**：在规定时间内提交项目仓库

### 赛道选择

- **开源项目开发赛道**：适合喜欢编程开发的选手
- **软件供应链安全赛道**：适合关注安全的选手
- **开源社区运营赛道**：适合擅长组织协调的选手

### 重要时间节点

- 报名时间：2025年1月 - 3月
- 初赛时间：2025年4月 - 6月
- 复赛时间：2025年7月 - 8月
- 决赛时间：2025年9月
